# Simple Name Registry (ENS-like): Map an Ethereum address to a human-readable string (name)

## Project Description
This project is a simple Ethereum smart contract that mimics the basic functionality of the Ethereum Name Service (ENS). It allows users to register, update, and remove human-readable names associated with their Ethereum addresses. This makes it easier to identify addresses on the blockchain without relying on long hexadecimal strings.

## Project Vision
Our goal is to create a lightweight, decentralized name registry that improves the user experience on Ethereum by bridging the gap between cryptographic addresses and human-readable identities. This service aims to make blockchain interactions more intuitive and accessible to everyday users.

## Key Features
- **Register or update a name:** Users can link their Ethereum address to a human-readable name.
- **Lookup names:** Anyone can query the contract to find the name associated with any Ethereum address.
- **Remove names:** Users have the ability to remove their registered name from the registry.
- **Gas-efficient and simple:** The contract is designed with simplicity and minimal gas usage in mind.

## Future Scope
- Integrate with ENS or other decentralized naming protocols for enhanced compatibility.
- Support reverse resolution to get addresses from names.
- Implement name expiration and renewal systems to prevent name squatting.
- Enable transfer and authorization control of names for added security.
- Develop a frontend interface for easier interaction and usability.
